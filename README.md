# Minor Project 2 – Spotify Tracks EDA

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Spotify Tracks dataset to identify patterns and relationships among track characteristics and popularity.

## Dataset
Spotify Tracks Dataset | Audio Features

Source: Kaggle
Dataset Link: https://www.kaggle.com/datasets/saichaitanyareddyai/spotify-tracks-dataset-audio-features/data?

## Analysis Performed
- Dataset understanding
- Missing-value analysis
- Duplicate-value analysis
- Data cleaning
- Categorical analysis
- Descriptive statistics
- Univariate analysis
- Bivariate analysis
- Correlation analysis
- Multivariate analysis
- Linear regression
- Model evaluation
